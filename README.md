# 石のプロフィール帳

## 公開のしかた(GitHub Pages)
1. このフォルダの中身をすべてリポジトリの直下に置いて push
2. Settings → Pages → Branch を main / (root) にして保存
3. 表示された URL を iPhone の Safari で開く
4. 共有ボタン →「ホーム画面に追加」

一度開けば、以降はオフラインでも起動・編集・保存できます。

## データについて
- データはその端末のブラウザ(localStorage)に保存されます
- 端末やブラウザが変わると引き継がれないので、「バックアップ」の文字を時々メモに控えてください
- 新しい端末では「読み込む」に貼り付けると元に戻ります

## 更新したとき
index.html などを直したら、sw.js の `CACHE` の番号を上げてから push してください(例: v1 → v2)。
次にオンラインで開いたときに新しい版に切り替わります。
